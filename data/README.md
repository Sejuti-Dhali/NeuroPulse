# Synthetic Physiological Dataset

File: `synthetic_readings.csv`

Number of observations: 120

Columns:

- `step`: sequential sample index
- `heartRate`: illustrative heart rate in beats per minute
- `temperature`: illustrative temperature in degrees Celsius
- `spo2`: illustrative oxygen saturation percentage
- `gsr`: arbitrary raw skin conductance-related signal units

The dataset is generated mathematically and is not derived from physical experiments or patients.

The browser also generates synthetic measurements using a seeded JavaScript random-number generator.
