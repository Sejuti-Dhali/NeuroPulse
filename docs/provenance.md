# Research Provenance and Limitations

NeuroPulse is a newly developed browser demonstration informed by the original group project titled *MindMonitor: A Web-Based Telemedicine Platform for Mental Health Monitoring*.

The software source code in this repository is a reconstructed demonstration, not a copy of the original group's implementation.

Synthetic physiological measurements are mathematically generated for software testing and interface visualization.

No real patient data, physical sensor recordings, validated stress predictions, or clinical diagnoses are included.

The application is not a medical device.
